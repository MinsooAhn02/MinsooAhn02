## 📌 Featured Work

### 📄 Research

**[Treatment-Correlated Instrument Error in Post-Fine-Tuning Safety Evaluation: A Single-Family Case Study](https://github.com/MinsooAhn02/weight_lens_safety)**<br>
Sole author · Accepted at the **NeurIPS 2026 Workshop on Foundations of Language Model Security (FLMSec)** (non-archival)

A fine-tuned adapter can pass a default-prompt safety check and still behave differently under the system prompt it is deployed with, so safety should be evaluated per (checkpoint, prompt) pair. Along the way I found and fixed two measurement errors that were correlated with the fine-tuning treatment. This is a case study on one model family (Llama-3.1-8B-Instruct).
